실시간 검색 가능

전혀 없습니다. 출결메이트는 외부 데이터베이스 서버가 존재하지 않는 100% 로컬 기반 웹 애플리케이션입니다.

선생님께서 입력하신 학생 이름, 번호, 결석 사유 등 모든 민감 데이터는 선생님 PC 웹 브라우저 로컬 저장소(IndexedDB)에만 암호화되어 보관됩니다. 어떠한 데이터도 외부 서버나 개발자에게 전송되지 않으므로 안심하고 사용하셔도 됩니다.

나이스 탭의 [학적 - 출결관리 - 일일출결관리] 메뉴가 브라우저 내에서 열려 있는지 먼저 확인해 주세요.

나이스 세션이 일정 시간 지나 만료되었을 경우 연결이 끊어질 수 있습니다. 나이스 페이지에서 F5(새로고침)를 누르신 후 본 대시보드로 돌아오시면 상단 헤더에 'NEIS 확장 연결됨' 초록 불이 다시 점등됩니다.

본 도구는 오직 대한민국 '중학교' 교시 체계(1~7교시)와 중등 출결 기준에만 맞춰 개발되었습니다.

고등학교의 경우 단위제, 이수 학점 구조, 고유 결석 산정 방식이 달라 나이스 주입 시 치명적인 데이터 오염이 발생할 수 있습니다. 고등학교 선생님들께서는 '내모ai' 등 고등 전용 소프트웨어를 활용해 주시길 간곡히 부탁드립니다.

네, 문제없이 전송 가능합니다.

증빙 서류 확인란(체크박스)은 선생님께서 학부모님께 결석계나 진단서 수합 여부를 자체적으로 점검하시기 위한 담임 전용 편의 메모 기능입니다. 체크 여부와 무관하게 나이스 대기열에는 사유와 교시 정보가 정확히 전송됩니다.
