# 출결메이트 확장 (#5 뼈대)

Chrome Manifest V3. 유저스크립트 없음.

## 하는 일

- `*.neis.go.kr`에서 **일일출결관리(담임용)** 화면인지 감지
- 권한: 나이스 호스트 + `http://localhost:5173`만
- 팝업에 「담임용 / 아님」표시
- 담임용이면 확장 배지 `ON`

## 하지 않는 일

- `<all_urls>`
- 나이스 로그인·인증서·SSO
- P칸 클릭·`/` 타이핑·저장·출결마감
- 그리드 셀렉터 추측
- 웹앱 ↔ 확장 대기열 메시지 (#6)
- 로그에 이름·출석번호

## 로드

1. `chrome://extensions` → 개발자 모드
2. 「압축해제된 확장 프로그램을 로드합니다」→ 이 `extension/` 폴더
3. 나이스 담임용 일일출결 탭을 연 뒤 확장 아이콘 확인

웹앱 origin이 Vite 기본이 아니면 `manifest.json`의 `host_permissions`를 같이 고친다.
