# 코딩 전에 열 이슈

봇은 이슈 없이 코드를 시작하지 않는다. 아래 순서를 지킨다.

## 0. 공통

- 샘플은 `학생01`만. 실명 CSV·원본 캡처는 이슈에 붙이지 않는다.
- 나이스 셀렉터는 추측하지 않는다. 화면을 본 뒤에만 매크로 구현 이슈를 연다.
- 스택: Vite + React + TypeScript, 확장 Manifest V3.
- 계약: `docs/data-contract.md`

## 1. `docs` 데이터 계약 고정

- 라벨: `docs`
- 목표: `category` / `type` / `period` / 상태 값이 웹앱·확장이 같이 쓰도록 이 문서를 기준으로 확정
- 수용: 문서에 없는 코드를 제안하는 PR은 반려

## 2. `web` 뼈대 + IndexedDB

- 라벨: `web`
- 목표: 가명 명단 CSV 가져오기, 로컬 저장
- 수용: 외부 전송 없음. `.env` 없음

## 3. `web` `ui` 출결 입력

- 라벨: `web` `ui`
- 목표: 날짜·학생·구분·종류·기준 교시 P·사유. 미리보기
- 수용: 기타면 사유 필수. 출석 행은 대기열에 안 넣음

## 4. `macro` 확장 뼈대

- 라벨: `macro`
- 목표: MV3, `*.neis.go.kr` + 웹앱 origin만. 일일출결관리(담임용) 화면 감지
- 수용: `<all_urls>` 없음. 로그인 자동화 없음. 셀렉터 하드코딩 남발 없음

## 5. `macro` 웹앱 ↔ 확장 메시지

- 라벨: `web` `macro`
- 목표: 대기열 JSON을 확장에 넘기고 origin을 검사
- 수용: sender 미확인 메시지 거부

## 6. `macro` `needs-teacher-review` 클릭·저장

- 현장 화면 검토 후에만 연다.
- 목표: 구분·종류 설정 → P 칸 클릭 → `/` 범위 확인 → 저장
- 수용: 출결마감 버튼 안 누름. 저장 없이 날짜 변경 안 함. 미리보기 없는 저장 경로 없음

## 총괄에게 줄 첫 말

코드 작성 금지. FIRST-ISSUES 1~5를 이슈 초안으로만 만든다. 샘플은 가명. 나이스 셀렉터는 추측하지 않는다.
