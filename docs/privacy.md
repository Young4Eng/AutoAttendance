# 출결 초안 개인정보 안내 (초안)

법률 자문이 끝난 문장이 아니다. 학교 개인정보 보호책임자 확인 후 확정한다.  
앱에 보이는 문구는 이 파일을 원문으로 한다.

## 앱 어디에 보여 주는가

| 위치 | 무엇을 |
| --- | --- |
| 로그인 직후 한 장 | 아래 「짧은 안내」 + 「확인」 |
| 사이드바 **사용 방법 → 개인정보 안내** | 이 파일 전문 |
| 이번 달·미리보기 상단 배너 | 짧은 안내 + 「자세히」링크 |
| 계정 **초안 삭제** 옆 | 파기 한 줄 |
| 명단 CSV 가져오기 직전 | 학생 성명이 DB에 저장된다는 한 줄 |

GitHub README에는 한 줄만: `개인정보 안내: docs/privacy.md`.  
학교 결재·학부모 동의서는 이 파일이 아니라 학교 양식을 쓴다.

## 짧은 안내 (배너·로그인)

출결 초안(번호·성명·사유)은 출결메이트 계정 DB에 저장됩니다.  
브라우저 캐시를 지워도 남고, 같은 구글 계정이면 다른 PC에서도 이어서 볼 수 있습니다.  
나이스에 이미 저장한 출결은 나이스에 있습니다. 이 DB는 초안입니다.  
자세히: 사용 방법 → 개인정보 안내

확인 버튼: 위 안내를 읽었고, 이 학급 출결 초안을 계정에 저장하는 데 동의합니다.

## 전문에 넣을 항목

- 처리 목적: 나이스 입력 전 초안 정리, 같은 계정으로 기기 이어보기
- 항목: 교사 구글 식별값·이메일·이름 / 학생 학년·반·번호·성명·날짜·구분·종류·교시·사유
- 안 받음: 주민번호, 사진, 학부모 연락처, 나이스 인증서·비밀번호
- 보유: 학년도 종료 또는 「계정 초안 삭제」 중 빠른 때
- 파기: 삭제 시 DB에서 제거
- 위탁: 실제 호스팅 업체명·지역 (예: Supabase)
- 구글: 로그인 신원만. 출결 원문 미전송
- 제3자 제공 없음 (법령 예외 제외)
- 열람·수정·삭제: 교사 화면 / 학생·보호자 요청 시 해당 행 삭제
- 거부: 이 앱을 쓰지 않고 나이스에 직접 입력

호스팅 업체·보관 기간이 바뀌면 이 파일을 고치고 개정 날짜를 남긴다.
