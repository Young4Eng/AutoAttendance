# 크롬 웹스토어 제출 초안 (출결메이트 1.0.0)

대시보드: https://chrome.google.com/webstore/devconsole  
패키지: `extension` 폴더 내용만 zip. 루트에 `manifest.json`이 있어야 한다.

## 스토어 소개

**이름**  
출결메이트

**요약(132자 이내)**  
중학교 담임이 나이스 일일출결에 넣기 전, 초안을 정리하고 화면에 보조 입력하는 확장입니다. 출결마감·로그인은 하지 않습니다.

**상세 설명**

출결메이트는 대한민국 중학교 담임교사를 위한 나이스 일일출결 보조 도구입니다.

웹(https://auto-attendance-six.vercel.app/)에서 학급 예외(결석·지각·조퇴·결과)를 정리한 뒤, 이 확장이 열려 있는 나이스 「일일출결관리(담임용)」 화면에 대기열을 넣습니다.

하는 일
- 웹에서 받은 대기열을 번호·성명으로 행을 찾아 구분·종류·교시·사유를 입력
- 날짜별 작업 후 나이스 저장 확인까지 보조
- 화면 밖 학생은 화살표로 스크롤하여 찾음

하지 않는 일
- 나이스 로그인, 공동인증서, 출결마감 버튼
- 학생 정보를 확장 제작자 서버로 전송

사용 순서
1. 출결메이트 웹에서 초안을 만들고 미리보기에서 확장으로 보냅니다.
2. 나이스 일일출결(담임용) 화면을 엽니다.
3. 주소창 오른쪽 퍼즐 아이콘에서 출결메이트를 연 뒤 「적용 후 저장」을 누릅니다.

## Privacy 탭 답안

**단일 목적**  
나이스 일일출결관리(담임용) 화면에 교사가 이미 정리한 출결 초안을 입력하는 보조.

**권한 이유**
- storage: 웹에서 받은 대기열을 브라우저 세션에 둠
- scripting, webNavigation: 나이스 출결 탭이 열렸는지 확인하고 해당 탭에서만 입력
- host `*.neis.go.kr`: 일일출결 화면 조작
- host localhost / 출결메이트 웹: 웹이 확장에 대기열을 넘김

**원격 코드** 사용하지 않음. 모든 스크립트는 패키지 안에 있음.

**이용자 데이터**
- 수집: 웹이 보낸 출결 초안(번호, 성명, 날짜, 구분, 종류, 교시, 사유). 나이스 비밀번호·인증서는 받지 않음.
- 전송: 제작자 서버로 보내지 않음. 이용자 브라우저 안에서 출결메이트 웹 ↔ 확장 ↔ 나이스 탭만 오감.
- 판매·광고 없음.

## 올린 뒤

1. 대시보드에 나온 **확장 ID**를 복사한다.
2. Vercel 환경변수 `VITE_EXTENSION_ID`에 넣는다.
3. 웹을 다시 배포한다. 미리보기의 「나이스로 전송」이 그 ID로 가야 한다.

심사에는 며칠이 걸릴 수 있다. 거절되면 이 문서의 Privacy 문장을 그대로 보강해 다시 제출한다.
