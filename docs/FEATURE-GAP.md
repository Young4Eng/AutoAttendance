# 시안 vs 프론트 vs 백엔드 — 기능 갭

비교 원본: `web/public/stitch/*/code.html` (정리본 Design.zip)  
구현: `web/src/screens/*` + `supabase/schema.sql`  
규칙: #55 종류/구분/P. 시안 마케팅 문장(v2.4, 호환율 100%, 104건)은 기능이 아님.

상태 약어  
- 있음: 지금 앱에서 동작  
- 반: 비슷하지만 시안 항목이 빠짐  
- 없음: 화면에도 DB에도 없음  
- 안 함: 시안에 있으나 만들지 않음(허위 스펙·개인정보)

## 명단 `stitch/roster` ← 당신이 말한 1~4가 여기

### 1) 명단 일괄 등록

시안: 버튼 + 텍스트 붙여넣기·파싱.  
당신 요구: 버튼 누르면 **헤더 채운 CSV 양식 다운로드**, 그 파일로 업로드.

| | 프론트 | 백엔드 |
| --- | --- | --- |
| CSV 업로드 → 명단 교체 | 있음 | `replaceRoster` (트랜잭션 아님) |
| 버튼 시 양식 다운로드 | **없음** | 파일 서버 불필요. 클라가 `grade,class,number,name` 헤더 CSV를 내려주면 됨 |
| 붙여넣기 파싱 | 없음 | 불필요 |

할 일  
- FE: `명단양식.csv` 다운로드(헤더만 또는 예시 1행). 업로드는 유지  
- BE: `replace_roster` 원자적 교체. 헤더 검증 에러 코드

### 2) 학생 추가

시안: `학생 추가` 버튼. 번호·성명 개별.

| | 프론트 | 백엔드 |
| --- | --- | --- |
| 버튼·폼 | **없음** | 행 upsert 없음(전체 교체만) |

할 일  
- FE: 번호, 성명, (학년·반 기본값). 번호 중복이면 막기  
- BE: `upsert_student(grade,class,number,name)`  
- 결번: 8번을 “추가”하지 않고 비워 두는 것이 기본. “결번 슬롯”을 명시 저장할지는 아래 3)

### 3) 상단 요약

시안: 재적 29명, 8번 결번, 배정 정원 30, 실제 재적 96.7%, 결번 1건, 나이스 슬롯 싱크.

| 항목 | 프론트 | 백엔드 | 할 일 |
| --- | --- | --- | --- |
| 재적 수 | 반(명단.length) | count면 됨 | 상단 카드 |
| 결번 수 | 반(max번호-인원) | 정원 없으면 추정만 | 정원 설정 필요 |
| 배정 정원 | **없음** | 컬럼 없음 | 교사 설정 `capacity` (예 30) |
| 결번 목록(8번) | **없음** | 없음 | 정원 1..N 중 roster에 없는 번호 |
| 나이스 슬롯 싱크 문구 | 안 함 | — | 나이스를 안 읽음. “번호=나이스 번호” 안내 문구만 |

### 4) 표 컬럼 + 관리 ⋯

시안 컬럼: 번호 / 성명 / 특이사항 및 학적 상태 / 출결 메모 연동 / 관리.

| 컬럼 | 프론트 | 백엔드 | 할 일 |
| --- | --- | --- | --- |
| 번호 | 있음 | 있음 | |
| 성명 | 있음 | 있음 | |
| 학적 상태 | **없음** | 없음 | `status`: 재학 / 전출(결번) / (선택)휴학 |
| 특이사항 | **없음** | 없음 | `note` 짧은 텍스트. 나이스에 안 보냄 |
| 출결 메모 연동 | **없음** | 없음 | 이번 달 그 학생 draft 건수 링크. entries 집계 |
| 관리 ⋯ | **없음** | 단건 삭제/수정 없음 | 수정(이름·번호·상태·메모), 삭제(재학 행만). 결번 슬롯은 “당기지 않음” |

필터 시안: 전체 / 재학 / 결번. 검색은 있음.

하단 시안 “하단에 연속 번호 추가” = 다음 빈 번호부터 여러 명. 2)의 확장. 1차 아님.

## 백엔드에 지금 없는 컬럼 (명단 때문에 필요)

```
teachers 또는 settings
  owner_id, grade, class, year, semester, capacity, agreed_at

roster 추가
  status  'enrolled' | 'transferred'   -- 전출=결번 슬롯
  note    text                         -- 특이사항. 확장 미전송

entries 는 유지 + CHECK (#55)
```

`출결 메모 연동`은 컬럼이 아니라 `entries`에서 그 번호 count.

## 우선순위 (구현할 때)

1. 명단 양식 다운로드 + 학생 추가 + ⋯ 수정/삭제 + 상단 재적/결번  
2. roster `note`/`status` + settings `capacity`  
3. entries CHECK + `apply_repeat` + `replace_roster` 트랜잭션  
4. 달력 월 집계·범례  
5. 미리보기 필터(선택)

나이스 슬롯 동기화, 웹스토어, 시안 개발자 정보, v2.4 스펙은 안 함.
