# 출결메이트 보안정책

시행일: 2026-09-06

「개인정보의 안전성 확보조치 기준」 및 개인정보위 안내서(2024.10.)의 항목에 맞춰, **이 서비스가 실제로 하는 조치**만 적습니다.  
기술적 금지 목록은 저장소 `SECURITY.md`를 따릅니다.

## 적용 원칙

처리할 정보가 적고 이용자는 교원입니다. 조치 수준은 그에 맞게 하되, 학생 성명·출결 사유가 있으므로 공개 저장소·공개 버킷에 원문을 두지 않습니다.

## 내부 관리

- 운영자가 개인정보 처리 목적·항목을 이 문서와 처리방침에 고정합니다.  
- service_role, DB 비밀번호, 마스터 키는 브라우저·깃에 올리지 않습니다.

## 접근 권한

- 이용자는 본인 `auth.uid()` 행만 읽기·쓰기 (Row Level Security).  
- 타인 `owner_id`를 바꿔 요청해도 거부합니다.  
- 역할(관리자)을 브라우저 저장 값으로 판단하지 않습니다.

## 접근 통제

- 웹은 HTTPS(Vercel).  
- 로그인은 구글 OAuth. 서비스가 비밀번호를 보관하지 않습니다.  
- 확장의 외부 메시지는 허용한 웹 주소(`localhost`, 배포 도메인)만 받습니다.

## 암호화

- 전송 구간 TLS.  
- 비밀번호 해시 대상이 없습니다(구글 위임).  
- 백업 파일을 공개 폴더에 두지 않습니다.

## 접속 기록

- 호스트(Vercel·Supabase)가 제공하는 기본 로그.  
- 학생 초안 원문을 로그에 남기지 않도록 앱을 작성합니다.

## 악성코드·물리·재해

- 개인 노트북 운영. 별도 IDC 없음.  
- 장애 시 초안은 DB에 남아 있고, 나이스 공식 값은 나이스에 있습니다.

## 개발 시 금지 (SECURITY.md와 같음)

브라우저에서 비밀번호 비교, service_role 프론트, SQL 문자열 접합, 스토리지 public, 배포물에 `.env` 포함.

## 사고

유출이 확인되면 이용자에게 알리고, 법령이 정한 경우 개인정보보호위원회 등에 신고합니다.
